Telegram Video Rewards Mini App Telegram Mini App for watching videos with a rewards and discounts system

Functionality

Star System

Watch Video

+1 star for watching 80% of a video

Subscribe to Channel

+1 star for subscribing

Invite a Friend

+1 star via the referral system

Reward

3 stars = 60 000 RUB discount

Project Structure

backend/ app.py # FastAPI server database.py # Database configuration models.py # SQLAlchemy models requirements.txt # Python dependencies frontend/ index.html # Main Mini App page css/ style.css # Styles js/ app.js # Client-side logic bot/ bot.py # Telegram bot .env.example # Environment variables example README.md

Installation and Setup

1. Create the Bot

  1. 1Open @BotFather in Telegram
  2. 2Create a new bot: /newbot
  3. 3Copy the bot token
  4. 4Enable Mini App: /newapp → select the bot → enter the app URL

2. Environment Setup

bash# Clone the repository
git clone <repository-url>
cd telegram-video-rewards

# Copy configuration
cp .env.example .env

# Edit .env
nano .env

Fill in the variables:

Variable Description
BOT_TOKEN Token from BotFather
CHANNEL_ID Channel username (e.g., @mychannel)
WEBAPP_URL URL where the app is hosted
API_URL API server URL

3. Start the Backend

bashcd backend

# Create virtual environment
python -m venv venv
source venv/bin/activate  # Linux/Mac
# or
venv\Scripts\activate     # Windows

# Install dependencies
pip install -r requirements.txt

# Start the server
uvicorn app:app --reload --host 0.0.0.0 --port 8000

4. Start the Bot

bashcd bot

# Activate environment (if not active)
source ../backend/venv/bin/activate

# Start the bot
python bot.py

5. Host the Frontend

For local development, use the built-in server:

bashcd frontend
python -m http.server 3000

For production, recommended options:

nginx
Cloudflare Pages
Vercel
Netlify

Adding Videos

Videos are added via the database. SQL example:

sqlINSERT INTO videos (title, description, video_url, thumbnail_url, duration_seconds, reward_stars)
VALUES (
    'Video Title',
    'Video Description',
    'https://example.com/video.mp4',
    'https://example.com/thumbnail.jpg',
    120,
    1
);

Or via Python:

pythonfrom models import Video
from database import async_session

async def add_video():
    async with async_session() as session:
        video = Video(
            title="New Video",
            description="Description",
            video_url="https://example.com/video.mp4",
            thumbnail_url="https://example.com/thumb.jpg",
            duration_seconds=120,
            reward_stars=1
        )
        session.add(video)
        await session.commit()

Deploy to Server

Docker (recommended)

Create a docker-compose.yml:

yamlversion: '3.8'

services:
  backend:
    build: ./backend
    ports:
      - "8000:8000"
    env_file:
      - .env
    volumes:
      - ./data:/app/data

  bot:
    build: ./bot
    env_file:
      - .env
    depends_on:
      - backend

  nginx:
    image: nginx:alpine
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./frontend:/usr/share/nginx/html
      - ./nginx.conf:/etc/nginx/nginx.conf

Manual Deploy

  1. 1Install Python 3.9+
  2. 2Configure nginx as reverse proxy
  3. 3Use systemd for auto-starting services
  4. 4Obtain an SSL certificate (Let's Encrypt)

Security

  • All requests are validated via Telegram initData
  • Referral codes are generated cryptographically
  • Rewards are credited only once per action
  • Video progress is tracked on the server
